# WeatherExplo AI
A simple AI-powered weather assistant built using Python, Streamlit, and Ollama. It retrieves current weather data for cities around the world and uses a locally running LLM to generate helpful weather advice.

Features

Search for weather by city.

View temperature, feels-like temperature, humidity, wind speed, and precipitation.

Get AI-generated weather advice using Ollama.

Simple conversational interface built with Streamlit.

Tech Stack

Python

Streamlit

Ollama (Llama 3.2)

Open-Meteo Weather API

Weather Data

Weather information is retrieved from Open-Meteo.
